# Atharva Shastrakar — Portfolio

Cybersecurity Analyst & Full Stack Developer. Static site with no build step: open `index.html`, or host the folder on GitHub Pages.

- `assets/js/data.js` — all text content (experience, project cards, skills, education, certifications, stats).
- `assets/js/projects.js` — project case-study details and architecture diagrams.
- `assets/js/site.js` — rendering, loading gate, terminal, security lab (ciphers, password analyzer).
- `assets/css/site.css` — styles. Colours are the variables at the top (`--g` green, `--r` red, `--y` amber).
- `assets/documents/` — resume PDF.
